# 產品客服 Agent 專案

## 專案簡介

這是一個以「拖拉式 AI Agent」平台（Coze）建置的**產品客服 Agent** 初步構想。目標是打造一個能自動回應顧客常見問題、查詢訂單狀態，並在必要時轉接真人客服的智慧客服機器人。

本專案為 AI 導論課程的學習實作，會隨著課程單元逐步擴充功能與知識庫。

## 目標使用者

- 電商平台的一般消費者，購買前後有問題需要即時解答
- 客服團隊，希望透過 Agent 分擔重複性高的詢問，把心力留給複雜案件

## 使用場景（Use Case）

以一間中小型網路商店為例：

1. 顧客在官網或 LINE／FB 訊息詢問「我的訂單什麼時候會到？」
2. Agent 先辨識問題類型（物流查詢 / 退換貨 / 商品規格 / 其他）
3. 若是可由知識庫或訂單系統直接回答的問題（如物流查詢、退換貨政策），Agent 直接生成答案
4. 若問題超出 Agent 能力範圍（例如客訴、情緒較激動的顧客），Agent 主動轉接給真人客服，並附上對話摘要

## 核心功能規劃

- **常見問題（FAQ）自動問答**：串接知識庫，回答退換貨政策、運費、商品規格等
- **訂單狀態查詢**：串接訂單系統 API，即時回覆物流進度
- **情緒 / 複雜度判斷**：辨識何時該轉人工客服
- **多輪對話記憶**：能記住同一顧客在對話中提到的資訊，避免重複詢問

## 技術構想

- 使用 Coze 平台的拖拉式介面建置 Agent 流程（節點串接：意圖判斷 → 知識庫檢索 / API 呼叫 → 回覆生成 → 轉人工）
- 知識庫先以常見問題文件（FAQ 文件）建立，之後視課程進度加入向量檢索
- 以 GitHub 記錄專案發展與每週進度報告
